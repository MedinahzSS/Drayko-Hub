DRAYKO UNIVERSAL - UI starter para Roblox Studio

Este projeto é um modelo de interface para usar no seu próprio jogo no Roblox Studio.
Não é um executor nem inclui funções de cheat para jogos de terceiros.

COMO USAR
1. Abra o Roblox Studio e seu próprio jogo.
2. Em Explorer, encontre StarterPlayer > StarterPlayerScripts.
3. Crie um LocalScript chamado DraykoUI.
4. Copie o conteúdo de main.lua para esse LocalScript.
5. Execute Play para testar a interface.

ARQUIVOS
- main.lua: cria a interface e os controles.
- settings.lua: exemplo de configurações para consulta; não precisa ser instalado separadamente.

OBSERVAÇÃO
O carregador loadstring(game:HttpGet(...)) não é necessário para esta versão no Roblox Studio.
Para código de jogo próprio, prefira colocar os scripts diretamente no projeto e usar ModuleScripts quando quiser separar partes.
